Research Talks

Europas digitale Abhängigkeit: Es ist Zeit für einen eigenen Web-Index

GI AK-OSS Themenabend talk on European digital sovereignty and the Open Web Index. Compresses the OWI usage story, expands the technical depth on OWI architecture, and adds the OUR²S retrieval system: vision of distributing retrieval across legal entities by language and topic partition, real cluster operation numbers, and the YOARS agent surface.

OpenWebSearch as a Data Source for AI

TPC26 LRZ satellite talk on the web as a data source for AI systems, using OpenWebSearch.eu as background infrastructure and focusing on training data, RAG memory, agentic search, software discovery, and behavioral traces.

OpenWebSearch.eu - Building an Open Index of the Web on HPC Infrastructure

HPCSE 2026 talk on OpenWebSearch.eu and the Open Web Index as open web-scale data infrastructure for AI, search, embeddings, agentic retrieval, and agent collaboration. Focuses on how OWI uses HPC and LEXIS in practice.
