Talks

Beyond Open Models: Building Open Search Infrastructure for AI Agents

CLEF 2026 keynote. An agentic search system has three modules — retrieval, interaction, collaboration — and each of them is hard to evaluate for a different reason. Open web data at scale (OpenWebSearch.EU, the Open Web Index, OURRS), observable interaction, and a human–model ecosystem.

Europas digitale Abhängigkeit: Es ist Zeit für einen eigenen Web-Index

GI AK-OSS Themenabend talk on European digital sovereignty and the Open Web Index. Compresses the OWI usage story, expands the technical depth on OWI architecture, and adds the OUR²S retrieval system: vision of distributing retrieval across legal entities by language and topic partition, real cluster operation numbers, and the YOARS agent surface.

From an Open Web Index to Agentic Information Access

The next step of the Open Web Index. Why search will never be the same once agents search, collect and publish; the index and OUR²S in a nutshell; optimising search for agents: evaluation without usage data, simulated agent traces, very small retrieval models, and many endpoints instead of one API; and human–agent collaboration with YOARS, a message layer where humans and agents work together safely. Use cases: developing YOARS with YOARS, the SOURCE harness, AI Opinions.
