SOURCE

Scalable, Open and Comprehensive Recognition of Disinformation Campaigns in the Web

disinformationweb-searchNLPAIinfrastructure
Funding AgencyBMFTR, programme "Digital. Sicher. Souverän."
Duration36 months, April 2026 to March 2029
CoordinatorProf. Dr. Michael Granitzer, University of Passau
PartnersUP, UK, OSF, LRZ, A4E
Statusactive

Project goal

SOURCE addresses disinformation by building an openly accessible database of potential disinformation artefacts, extending the Open Web Index with collaborative infrastructure for large-scale web and social-media analysis.

Technical approach

Data collection

Extension of web crawling to include social media and multimedia tracking via similarity-preserving hashes.

Content-based analysis

AI-generated text detection, stylometry, fact-checking agents, and scalable filtering.

Provenance-based analysis

Temporal diffusion analysis, actor identification, and network tracing of coordinated campaigns.
